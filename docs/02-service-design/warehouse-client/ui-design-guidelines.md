# 仓库端 UI 设计规范

## 1. 视觉定位

仓库端采用独立蓝色主题，强调高可读性、高密度信息和扫码作业效率。主色为 `#2563EB`，与 H5 客户端共享间距、圆角、阴影和字体令牌。

## 2. 导航结构

底部导航固定四项：

| Tab | 页面 |
|-----|------|
| 工作台 | 作业统计和入口 |
| 拣货 | 待拣货任务 |
| 复核 | 复核打包任务 |
| 出库 | 出库交接任务 |

库存查询可从工作台或业务入口进入。

## 3. 设备适配

1. 以 PDA 竖屏为主要布局。
2. 按钮、输入框和扫描区域需要足够大，便于手持操作。
3. 页面避免复杂横向表格，优先使用任务卡片和分组字段。
4. 扫码成功、失败和异常需有明显视觉反馈。

## 4. 组件规范

| 组件 | 规范 |
|------|------|
| `ScanInput` | 固定扫码入口，支持自动聚焦、手动输入和清空 |
| `TaskCard` | 展示任务号、订单号、SKU 数、包裹数、状态和主操作 |
| `StatusTag` | 使用颜色区分待处理、处理中、完成、异常 |
| `EmptyState` | 用于无任务、无库存结果和网络异常 |

## 5. 页面规范

1. 工作台优先展示待办数量和异常数量。
2. 拣货页突出库位、SKU、应拣数量和已拣数量。
3. 复核页突出差异项、重量、体积和包裹信息。
4. 出库页突出包裹码、海关同步状态和交接确认。
5. 库存查询页突出 SKU、可用库存、锁定库存、库位和批次。

## 6. 文案规范

1. 作业反馈使用短句，例如“扫码成功”“数量不一致”“海关同步未通过”。
2. 异常信息必须说明阻断原因。
3. 中英文文案都需要适配窄屏，不使用过长按钮文本。
