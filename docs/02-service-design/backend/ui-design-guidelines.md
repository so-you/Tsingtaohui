# 后端服务 UI 与接口展示规范

## 1. 适用范围

后端服务不提供独立业务 UI。本文件用于约束 API 文档、错误响应、运维页面和管理端展示所需的数据表达方式。

## 2. API 文档规范

1. API 文档按业务域分组：认证、商品、库存、订单、仓库、配送、海关、管理、权限。
2. 每个接口必须说明请求方法、路径、权限、请求参数、响应结构和错误码。
3. 状态字段必须引用统一枚举，不在接口文档中新增临时状态。
4. 示例数据不得包含真实客户数据、真实 token、生产端点或密钥。

## 3. 错误响应规范

错误响应统一包含：

```json
{
  "code": "ORDER_INVENTORY_NOT_ENOUGH",
  "message": "库存不足",
  "data": null
}
```

1. `code` 用于前端映射和问题定位。
2. `message` 用于默认展示，应简短清晰。
3. 字段级校验错误可在 `data` 中返回字段列表。

## 4. 运维展示规范

1. 健康检查展示服务状态、数据库连接、Redis 连接和外部系统可用性。
2. 外部系统调用日志展示请求时间、耗时、结果和错误摘要。
3. 海关同步记录展示节点类型、同步状态、重试次数和最后响应时间。
4. 无人机回调日志展示回调 ID、任务 ID、状态和幂等处理结果。

## 5. 管理端数据展示约束

1. 后端应返回管理端直接可展示的状态文案 key 和状态枚举。
2. 时间字段统一使用 ISO 8601 或项目约定格式。
3. 金额、重量和体积字段返回数值与单位约定，避免前端猜测单位。
4. 敏感字段默认脱敏，管理端需要明文时必须经过权限校验。
