# 管理端 UI 设计规范

## 1. 视觉定位

管理端采用 Element Plus 后台管理风格，界面应安静、清晰、信息密度适中，优先支持运营人员高频查询、筛选、比对和处理异常。

## 2. 布局规范

1. 使用左侧菜单、顶部用户区和主内容区。
2. 列表页采用“筛选区 + 操作区 + 表格 + 分页”结构。
3. 详情信息优先使用详情页或抽屉，避免在表格中堆叠过多字段。
4. 页面区域不使用多层卡片嵌套。

## 3. 表格规范

1. 表格列需要支持订单号、状态、时间等核心字段快速识别。
2. 状态字段使用颜色标签，但不得只依赖颜色表达含义。
3. 行操作控制在常用操作内，低频操作放入更多菜单。
4. 长文本使用省略和悬浮提示。

## 4. 筛选规范

1. 常用筛选项放在首行：关键词、状态、时间范围。
2. 高级筛选可以折叠。
3. 查询和重置按钮位置固定。
4. 筛选参数需要能反映到当前列表状态，便于刷新后恢复。

## 5. 状态规范

| 类型 | 展示方式 |
|------|----------|
| 订单状态 | 标签 + 文案 |
| 仓库状态 | 标签 + 当前节点 |
| 配送状态 | 标签 + 无人机任务信息 |
| 海关同步 | 红牌阻断、黄牌警告、成功和重试中明确区分 |
| 异常 | 使用醒目标识和原因摘要 |

## 6. 操作规范

1. 取消订单、异常标记、库存调整和规则变更需要二次确认。
2. 成功和失败反馈使用统一消息组件。
3. 对不可操作状态禁用按钮并说明原因。
4. 敏感操作在权限不足时不展示或展示禁用状态。
