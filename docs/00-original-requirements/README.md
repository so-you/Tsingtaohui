## 维护规则

1. 新增原始需求、会议纪要、讨论结论或业务方修改意见时，按日期命名放入本目录。
2. 被确认纳入开发基线的内容，需要同步更新 `../01-product-design/` 和对应服务目录。
3. 原始资料不直接修改为实现文档；如需修订，新增版本或在文档中记录变更日期。
