# H5 客户端需求规格说明书

## 1. 服务定位

H5 客户端是船员端商城入口，负责把船员用户的商品购买需求转化为平台订单，并在配送完成后完成收货确认。

## 2. 用户角色

| 角色 | 说明 |
|------|------|
| 船员用户 | 注册登录、维护船舶信息、购买商品、跟踪订单、确认收货 |
| 收货人 | 订单中的实际收货对象，需填写姓名和舱位号 |

## 3. 功能范围

### 3.1 注册登录

1. 支持用户名和密码注册登录。
2. 注册时采集船舶信息：船号、国籍、IMO 或 MMSI。
3. 登录后保存会话状态，并在 API 请求中携带认证信息。

### 3.2 商品浏览

1. 支持首页推荐、商品分类、商品列表和商品详情。
2. 展示商品名称、图片、价格、库存、重量、体积和是否可无人机配送。
3. 商品列表支持按分类浏览，详情页提供加入购物车和立即购买入口。

### 3.3 购物车和订单

1. 支持加入购物车、调整数量、删除商品和结算。
2. 订单确认页必须填写收货人姓名和舱位号。
3. 提交前调用订单试算，校验库存、重量、体积、服务时间和无人机配送规则。
4. 创建订单后展示交易模式：自动交易或撮合订单。

### 3.4 订单跟踪

1. 支持订单列表和订单详情。
2. 展示订单状态、仓库状态、配送状态和海关同步提示。
3. 异常或取消订单需要展示明确原因。

### 3.5 我的页面

1. 展示用户基础信息和船舶信息。
2. 支持维护船舶信息。
3. 提供扫码确认收货入口。
4. 支持中英文切换。

## 4. 状态和规则

1. 订单状态遵循整体状态流转：待提交、待确认、已确认、仓库处理中、待出库、已出库、待装载、配送中、待收货、已完成、已取消、异常。
2. 自动交易必须通过库存、重量、体积、无人机可用性、船舶位置、服务时间和海关数据完整性校验。
3. 撮合订单用于人工介入场景，包括超大件、多包裹、船舶位置不明确、特殊配送时间、库存不足但可调配、无人机匹配失败。

## 5. 验收标准

1. 用户可完成注册、登录、浏览商品、加入购物车、提交订单、查看订单和扫码收货。
2. 中英文文案覆盖首页、商品、订单、我的和关键错误提示。
3. 无效船舶信息、库存不足、超重和不可配送商品提交时有明确提示。
4. API 失败时页面保留当前上下文，不丢失用户已输入的关键信息。
