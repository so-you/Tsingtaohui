# 软件需求规格说明书

版本：V1.1  
日期：2026-05-28  
产品：青岛汇保税仓无人机配送平台  
适用阶段：一期 MVP 研发落地  

## 1. 产品定位

青岛汇面向青岛港货轮、船员、保税仓和平台运营方，提供从线上购物下单、保税仓履约、无人机配送、送货上船到海关节点同步的业务闭环。

一期重点交付可运行的软件系统，支持用户注册登录、H5 商城式购物、保税仓作业、管理端运营管理、订单状态追踪、无人机黑盒系统对接和海关同步记录。

## 2. 开发目的

1. 建立保税仓商品到货轮的线上下单和配送履约闭环。
2. 通过 H5 商城式界面降低外籍船员下单成本。
3. 建立用户账号和个人船舶资料，为后续身份校验、常用信息复用和订单归属提供基础。
4. 支持仓库拣货、复核、打包、出库和扫码作业。
5. 支持平台运营对商品、库存、订单、无人机、规则和海关同步的管理。
6. 支持中文和英文全流程切换。
7. 保留后续免注册一船一码、支付结算、港口周边商店和多商户扩展能力。

## 3. 用户角色

| 角色 | 使用端 | 核心诉求 |
|------|--------|----------|
| 船员/货轮用户 | H5 客户端 | 注册登录、维护个人和船舶信息、浏览商品、下单、追踪订单、确认收货 |
| 保税仓操作员 | 仓库端 H5 | 接单、拣货、复核、打包、出库、扫码校验、库存处理 |
| 平台运营人员 | 管理端 Web | 管理商品、库存、订单、用户、船舶、无人机、规则、海关同步和对账数据 |
| 无人机调度人员 | 管理端 Web | 维护无人机资料、查看匹配结果、人工指派和处理异常任务 |
| 海关系统 | 外部系统 | 接收订单和履约节点数据，返回同步结果 |
| 无人机系统 | 外部黑盒系统 | 接收配送任务，回调配送状态 |

## 4. 一期范围

### 4.1 一期包含

1. 用户名和密码注册、登录、退出。
2. 用户个人资料维护。
3. 个人资料中的船舶信息维护：船号、船籍、IMO 编码、MMSI 编码。
4. H5 客户端商城首页、商品列表、商品详情、购物车、订单确认、订单列表、订单详情、个人中心。
5. H5 客户端、仓库端和管理端全部页面与功能支持中文/英文切换。
6. “我的”页面提供扫码收货确认入口。
7. 商品分类、搜索、价格、库存和无人机配送标识展示。
8. 订单提交、自动交易/匹配订单判断、订单状态追踪。
9. 保税仓库存管理、拣货、复核、打包、出库交接。
10. 仓库端支持 PDA、蓝牙扫码枪和物理扫码枪的键盘回显输入。
11. 管理端订单、匹配订单池、商品、库存、无人机、规则、用户、船舶、海关同步和权限审计管理。
12. 无人机基础资料和自动匹配。
13. 无人机黑盒系统最小 API 契约。
14. 海关同步记录、红牌拦截和黄牌警告机制。
15. 船舶代理人字段、订单筛选和对账导出基础能力。

### 4.2 一期不包含

1. 免注册一船一码下单。
2. 在线支付、线上结算、优惠券、积分和发票。
3. 送海关查验流程。
4. 港口周边商店接入和复杂商户后台。
5. 多仓调拨。
6. 多无人机拆单配送。
7. 无人机飞控、航线审批、避障和飞行安全决策。
8. 无人机实时轨迹展示。

## 5. 总体业务流程

### 5.1 注册登录流程

1. 用户打开 H5 客户端。
2. 用户选择中文或英文。
3. 新用户使用用户名和密码注册。
4. 系统校验用户名唯一性和密码强度。
5. 注册成功后进入登录态。
6. 用户补充个人资料和船舶信息。
7. 用户进入商城首页开始选购。

### 5.2 下单履约流程

1. 用户登录 H5 客户端。
2. 用户进入首页或商品页浏览商品。
3. 用户搜索、筛选商品并查看商品详情。
4. 用户加入购物车或立即购买。
5. 用户在订单确认页确认商品、数量、价格、重量、体积、船舶信息、船舶代理人、收货人、Cabin No.、联系方式和期望送达时间。
6. 系统校验库存、重量、体积、无人机可配送标识、船舶信息、船舶代理人和必填字段。
7. 系统判断订单进入自动交易或匹配订单。
8. 订单创建节点进行海关同步。该节点为红牌拦截，同步成功后订单才可进入仓库作业。
9. 仓库端接收订单并锁定库存。
10. 仓库操作员拣货、扫码复核、打包并生成包裹。
11. 系统匹配无人机型号和架次，生成配送任务。
12. 仓库出库节点进行海关同步。该节点为红牌拦截，同步成功后才允许打印出库单和激活无人机任务。
13. 仓库完成出库交接。
14. 无人机系统执行配送并回调任务状态。
15. 用户在“我的”页面进入扫码收货，或在订单详情中输入验证码完成收货确认。
16. 订单完成，关键节点继续写入海关同步记录和审计日志。

## 6. 状态定义

### 6.1 订单状态

| 状态 | 编码 | 说明 |
|------|------|------|
| 待确认 | PENDING_CONFIRM | 订单已提交，等待系统自动确认或运营人工确认 |
| 已确认 | CONFIRMED | 订单通过规则校验或人工确认 |
| 仓库处理中 | WAREHOUSE_PROCESSING | 仓库正在拣货、复核或打包 |
| 待出库 | PENDING_OUTBOUND | 货物复核完成，等待出库交接 |
| 已出库 | OUTBOUND | 货物已离开仓库 |
| 待装载 | PENDING_LOADING | 货物等待无人机装载 |
| 配送中 | IN_DELIVERY | 无人机任务执行中 |
| 待签收 | PENDING_RECEIPT | 货物已到达，等待收货确认 |
| 已完成 | COMPLETED | 收货确认完成 |
| 已取消 | CANCELLED | 用户、运营或系统取消订单 |
| 异常 | EXCEPTION | 库存、配送、同步或签收环节异常 |

### 6.2 交易模式

| 模式 | 编码 | 说明 |
|------|------|------|
| 自动交易 | AUTO_TRADE | 订单满足自动校验条件，自动进入履约 |
| 匹配订单 | MATCHING_ORDER | 订单需要运营人工确认商品、配送方式、无人机资源或异常原因 |

### 6.3 海关同步状态

| 状态 | 编码 | 说明 |
|------|------|------|
| 未同步 | SYNC_NONE | 尚未发起同步 |
| 同步中 | SYNCING | 请求已发送，等待响应 |
| 同步成功 | SYNC_SUCCESS | 海关返回接收确认 |
| 同步失败 | SYNC_FAILED | 接口调用失败或海关返回失败 |
| 重试中 | RETRYING | 失败后进入自动重试 |
| 已人工处理 | MANUAL_RESOLVED | 管理员按合规流程处理完成 |

## 8. 业务规则

### 8.1 注册规则

1. 用户名全局唯一。
2. 密码长度不少于 8 位，必须包含字母和数字。
3. 密码仅存储不可逆哈希值。
4. 注册时默认语言可选中文或英文。
5. 注册成功后用户状态为启用。

### 8.2 下单校验规则

1. 用户必须登录。
2. 购物车不能为空。
3. 商品必须上架。
4. 商品可用库存必须满足购买数量。
5. 商品必须允许无人机配送，否则订单进入匹配订单或阻止提交，由管理端规则决定。
6. 总重量和总体积超过无人机能力时进入匹配订单。
7. 船舶信息、船舶代理人、收货人和 Cabin No. 为必填。
8. 海关必填字段不完整时订单进入异常或匹配订单。

### 8.3 自动交易规则

订单同时满足以下条件时进入自动交易：

1. 商品属于保税仓商品目录。
2. 商品库存充足。
3. 商品均允许无人机配送。
4. 总重量不超过可用无人机核载质量。
5. 总体积不超过可用无人机载荷空间。
6. 船舶信息和配送目标位置明确。
7. 船舶代理人已确认。
8. 配送时间处于可服务时段。
9. 海关同步字段完整。

### 8.4 匹配订单规则

满足以下任一条件时进入匹配订单池：

1. 商品超重或体积超限。
2. 需要拆分多包裹或多架次。
3. 船舶信息或配送位置不完整。
4. 配送时间特殊。
5. 库存不足但运营可调配。
6. 商品、价格、配送方式或服务动作需要人工确认。
7. 自动匹配无人机失败。
8. 海关字段不完整但允许运营补充。

## 10. 验收标准

1. 用户可完成注册、登录、资料维护、船舶信息维护、选品、下单、订单追踪和收货确认。
2. 客户端底部导航为：首页、商品、订单、我的。
3. “我的”页面包含扫码收货入口。
4. 客户端、仓库端和管理端所有页面和功能支持中文和英文切换。
5. 仓库端可完成拣货、复核、打包和出库交接，并兼容键盘回显扫码设备。
6. 管理端可完成商品、库存、订单、用户、船舶、无人机、规则和海关同步管理。
7. 订单创建和仓库出库红牌节点同步失败时，系统阻塞后续核心履约动作。
8. 后端使用 Spring Boot 和 JDK 17，数据库使用 MySQL。
9. 管理端使用 Vue 3 和 Element Plus。
10. 客户端和仓库端使用 Uni-app H5。
