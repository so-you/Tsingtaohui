# 后端服务需求规格说明书

## 1. 服务定位

后端服务负责承接 H5 客户端、仓库端和管理端请求，统一处理业务规则、状态流转、认证授权、数据持久化和外部系统集成。

## 2. 功能范围

### 2.1 用户和认证

1. 支持船员用户注册登录。
2. 支持仓库人员和管理端用户登录。
3. 密码使用 BCrypt 加密存储。
4. API 使用 JWT token 认证，并设置合理过期时间。

### 2.2 商品和库存

1. 管理商品、分类、重量、体积、可配送状态和商户预留字段。
2. 维护库存可用数量和锁定数量。
3. 下单时锁定库存，取消或异常时释放库存。
4. 仓库作业完成后更新库存和包裹状态。

### 2.3 订单履约

1. 创建订单时校验库存、重量、体积、船舶信息、服务时间和海关数据完整性。
2. 根据校验结果进入自动交易或撮合订单。
3. 维护订单状态、仓库状态、配送状态和海关同步状态。
4. 订单状态变更必须可追溯。

### 2.4 仓库作业

1. 提供待拣货、待复核、待出库任务接口。
2. 支持扫码校验 SKU、包裹、订单和库位。
3. 出库前执行红牌海关同步校验。

### 2.5 无人机集成

1. 查询无人机状态列表。
2. 派发配送任务。
3. 接收无人机状态回调。
4. Webhook 回调必须幂等处理。

### 2.6 海关同步

1. 订单创建和仓库出库为红牌拦截节点，同步失败时阻断流程。
2. 配送任务创建、无人机装载、配送中、已送达、已签收和订单异常为黄牌警告节点，同步失败时告警并重试。
3. 所有海关同步请求和响应必须完整记录。

### 2.7 管理和审计

1. 支持订单、撮合池、商品库存、无人机、规则、海关同步和 RBAC 管理 API。
2. 敏感操作记录审计日志。
3. 审计日志包含操作人、操作时间、对象、动作和结果。

## 3. 非功能需求

1. 核心 API 需要统一错误码和响应结构。
2. 外部系统调用需要超时、重试、日志和降级处理。
3. 关键状态变更需要事务保证。
4. 敏感接口必须配置访问控制。

## 4. 验收标准

1. 三个前端应用可以通过后端 API 完成主流程。
2. 红牌海关同步失败时订单创建或出库被阻断。
3. 无人机回调重复提交不会导致重复状态变更。
4. Service 层核心逻辑具备单元测试覆盖。
