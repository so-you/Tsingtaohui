# 仓库端需求规格说明书

## 1. 服务定位

仓库端是保税仓履约操作入口，负责把已确认订单转化为可交接给无人机配送系统的包裹出库记录。

## 2. 用户角色

| 角色 | 说明 |
|------|------|
| 仓库操作员 | 执行拣货、复核、打包、出库交接和库存查询 |
| 仓库主管 | 查看任务概览，处理异常任务 |

## 3. 功能范围

### 3.1 登录

1. 仓库人员使用账号密码登录。
2. 登录后进入工作台。
3. 未登录访问业务页时跳转登录页。

### 3.2 工作台

1. 展示待拣货、待复核、待出库和异常任务数量。
2. 展示今日完成量和关键任务入口。
3. 支持从工作台进入具体作业流程。

### 3.3 拣货

1. 展示待拣货任务列表。
2. 支持扫描库位、商品条码或任务码。
3. 校验 SKU、批次、数量和库位。
4. 拣货完成后更新仓库状态。

### 3.4 复核打包

1. 支持扫描订单、包裹和商品条码。
2. 校验商品明细、数量、重量和体积。
3. 生成或确认包裹信息。
4. 发现差异时进入异常处理。

### 3.5 出库交接

1. 展示待出库包裹。
2. 出库前必须确认红牌海关同步已成功。
3. 扫描包裹后完成出库交接。
4. 出库完成后等待无人机任务装载。

### 3.6 库存查询

1. 支持按 SKU、商品名、库位和条码查询库存。
2. 展示可用库存、锁定库存、批次和库位。
3. 查询页不直接修改库存。

## 4. 设备兼容

1. 支持 PDA 手持终端浏览器。
2. 支持蓝牙指环扫描器。
3. 支持键盘模拟输入的物理条码枪。
4. 扫码流程应减少手动输入和弹窗打断。

## 5. 验收标准

1. 操作员可完成登录、工作台查看、拣货、复核打包、出库交接和库存查询。
2. 扫码输入可处理快速连续字符输入和回车提交。
3. 红牌海关同步失败时不得继续出库。
4. Mock 数据可在开发环境通过 `VITE_USE_MOCK=true` 启用。
