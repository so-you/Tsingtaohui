# 管理端需求规格说明书

## 1. 服务定位

管理端是平台运营和后台管理入口，负责对订单、库存、无人机、规则、海关同步、用户和权限进行集中管理。

## 2. 用户角色

| 角色 | 说明 |
|------|------|
| 运营人员 | 查看订单、处理撮合订单、监控异常 |
| 仓库主管 | 查看仓库作业进度和库存 |
| 系统管理员 | 管理用户、角色、菜单和系统规则 |

## 3. 功能范围

### 3.1 订单管理

1. 支持按订单号、船舶、状态、交易模式和时间查询。
2. 展示订单状态、仓库状态、配送状态和海关同步状态。
3. 支持查看订单详情、商品明细、包裹和配送任务。
4. 支持取消、异常标记和人工备注等运营操作。

### 3.2 撮合池管理

1. 展示需要人工介入的订单。
2. 标明进入撮合池的原因。
3. 支持人工确认匹配、调整配送安排或转异常。

### 3.3 商品与库存管理

1. 管理商品基础信息、分类、价格、重量、体积和可配送状态。
2. 查看库存可用数量、锁定数量、仓库、库位和批次。
3. 库存调整需要记录审计日志。

### 3.4 无人机管理

1. 查看无人机机型、航班号、载重、体积、航程、可配送品类和状态。
2. 查看配送任务和调度记录。
3. 无人机系统不可用时展示降级提示。

### 3.5 规则配置

1. 配置服务时间、重量限制、体积限制、区域限制和品类限制。
2. 规则变更需记录操作人、时间和变更内容。

### 3.6 海关同步监控

1. 查看海关同步节点、请求、响应、状态、重试次数和时间戳。
2. 红牌拦截失败需要突出展示并支持人工处理。
3. 黄牌警告失败需要支持查看重试日志。

### 3.7 RBAC 权限

1. 支持用户、角色、菜单和按钮权限配置。
2. 敏感操作需要权限控制和审计记录。

## 4. 验收标准

1. 运营人员可以完成订单查询、撮合处理、异常跟踪和海关同步查看。
2. 管理员可以配置角色、菜单和规则。
3. 表格筛选、分页、详情抽屉或详情页可稳定展示大部分运营场景。
4. 无权限用户无法访问受限菜单和敏感操作。
