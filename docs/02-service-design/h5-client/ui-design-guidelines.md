# H5 客户端 UI 设计规范

## 1. 视觉定位

H5 客户端采用商城风格，参考有赞类移动端电商体验。界面应突出商品浏览、下单效率和订单状态可读性。

## 2. 导航结构

底部导航固定四项：

| Tab | 页面 |
|-----|------|
| 首页 | 推荐商品、服务提示、快捷入口 |
| 商品 | 分类、列表、搜索入口 |
| 订单 | 订单列表、状态筛选 |
| 我的 | 用户信息、船舶信息、扫码收货、语言切换 |

## 3. 页面规范

| 页面 | 关键要求 |
|------|----------|
| 首页 | 展示服务定位、推荐商品和订单入口，不做营销型大幅装饰 |
| 商品列表 | 商品卡片展示图片、名称、价格、库存和可配送标识 |
| 商品详情 | 展示重量、体积、无人机可配送状态和购买入口 |
| 购物车 | 支持数量调整、选择结算、金额和重量汇总 |
| 订单确认 | 收货人姓名、舱位号和船舶信息必须清晰可编辑 |
| 订单列表 | 使用状态标签和时间线摘要，便于快速识别进度 |
| 订单详情 | 展示订单、仓库、配送和海关同步节点 |
| 我的 | 信息层级简洁，扫码收货入口必须醒目 |

## 4. 组件规范

1. 商品卡片使用统一图片比例，避免列表跳动。
2. 价格、库存、重量和状态标签必须固定位置。
3. 主按钮用于提交订单、确认收货等关键动作。
4. 危险或不可逆动作使用二次确认。

## 5. 文案规范

1. 中文和英文文案语义一致，不使用硬编码。
2. 错误提示要说明原因和下一步动作。
3. 订单状态使用统一译名，避免同一状态多种表达。

## 6. 响应式

1. 以移动端 H5 为主，适配常见手机宽度。
2. 内容区域避免横向滚动。
3. 表单输入、扫码入口和底部按钮需要兼容安全区。
